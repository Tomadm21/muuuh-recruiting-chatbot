# Project Overview

## What is muuh WhatsApp Recruiting Chatbot?

The **muuh WhatsApp Recruiting Chatbot** is a production-ready conversational AI solution designed to automate the initial stages of the recruiting process. It interacts with potential candidates via WhatsApp, provides information about job openings, and performs initial screening through interactive Q&A.

## Core Purpose

- **Streamline Recruitment**: Reduce the manual workload of HR teams by automating candidate intake and FAQ answering.
- **Enhance Candidate Experience**: Provide instant, 24/7 responses to common questions about jobs and the company.
- **Qualified Lead Generation**: Automatically score and prioritize candidates based on their experience and skills.

## Technology Stack

- **Language**: Python 3.9+
- **Framework**: FastAPI
- **AI/NLP**: OpenAI GPT-4 (using function calling and classification)
- **Messaging**: Twilio WhatsApp API
- **Database**: SQLAlchemy (SQLite for development, PostgreSQL-ready)
- **Task Management**: (Optional) Celery/Redis for background processing

## Key Features

- **Natural Language Interaction**: Uses GPT-4 to understand candidate intent and provide human-like responses.
- **Dynamic State Machine**: A robust `FlowEngine` manages the conversion from generic chat to structured application data.
- **Lead Scoring**: Candidates are scored (0-100) based on pre-defined criteria (experience, tech knowledge, availability).
- **Admin Dashboard**: (In development) A Jinja2-based dashboard for viewing and managing candidate leads.
- **Automatic CV/Cover Letter Collection**: Handles document uploads directly through the WhatsApp interface.
